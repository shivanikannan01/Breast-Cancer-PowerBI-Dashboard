# Breast Cancer Analysis Dashboard

## About Breast Cancer

Breast cancer is one of the most frequently diagnosed cancers worldwide and a major concern in the healthcare industry. It develops when abnormal breast cells grow uncontrollably, forming tumors that may spread to other parts of the body if not detected early.

Early diagnosis plays a critical role in increasing survival rates and improving treatment effectiveness. Modern healthcare systems use data analytics and visualization tools to identify medical patterns, monitor diagnosis trends, and support data-driven clinical decisions.

This project uses a real-world breast cancer dataset containing medical attributes such as:

* Radius
* Texture
* Perimeter
* Area
* Smoothness
* Compactness
* Concavity
* Symmetry
* Fractal Dimensions

These features help in distinguishing between:

* **Malignant (M)** → Cancerous tumors
* **Benign (B)** → Non-cancerous tumors

---

# Project Overview

The **Breast Cancer Analysis Dashboard** is an interactive healthcare analytics project developed using **Power BI** to analyze breast cancer diagnosis data and transform raw medical information into meaningful visual insights.

The dashboard provides a clear understanding of patient diagnosis patterns, tumor characteristics, and medical feature distributions through dynamic visualizations and KPI indicators.

The project demonstrates how Business Intelligence and Data Analytics can be applied in the healthcare sector to support better analysis and decision-making.

---

# Dataset Information

## Dataset Details

* Total Records: **569 Patients**
* Total Features: **32 Columns**
* Dataset Type: Healthcare / Medical Diagnosis Data

## Important Columns Used

| Column                 | Description                  |
| ---------------------- | ---------------------------- |
| diagnosis              | Malignant (M) or Benign (B)  |
| radius_mean            | Average tumor radius         |
| texture_mean           | Surface texture details      |
| perimeter_mean         | Tumor perimeter measurement  |
| area_mean              | Tumor area measurement       |
| smoothness_mean        | Tumor smoothness             |
| compactness_mean       | Tumor compactness            |
| concavity_mean         | Severity of concave portions |
| symmetry_mean          | Tumor symmetry               |
| fractal_dimension_mean | Complexity of tumor boundary |
